## ✦ OSINT itu apa sih??

OSINT alias **Open-Source Intelligence** tuh basically seni ngumpulin informasi
dari sumber yang bisa diakses publik ehe~ jadi bukan hacking ilegal yaa bestie,
ini tuh _legal_ dan digunain sama investigator, jurnalis, cybersecurity researcher,
sama orang-orang iseng yang penasaran sama digital footprint seseorang wkwkwk

sumber-sumber yang biasanya dipake tuh kayak:

- sosial media (Instagram, Twitter/X, LinkedIn, TikTok, dsb)
- domain dan IP public records
- dokumen pemerintah dan database terbuka
- metadata foto dan file
- forum, paste sites, dark web indexes
- satellite imagery dan geolocation data

intinya kalau bisa diakses tanpa bypass sistem orang lain, itu OSINT ehe~

## ✦ Contoh Tools yang Ada di Sini

ini sebagian kecil dari 1167+ tools yang diindex, buat gambaran aja yaa uwu

**Identitas dan Sosmed**
- `Sherlock` ~~ cari username seseorang di 300+ platform sekaligus, keren banget
- `Maltego` ~~ visualisasi relasi antar entitas, favorit para investigator
- `SpiderFoot` ~~ automated OSINT scanning, ngumpulin data sendiri ehe

**Domain dan IP**
- `Shodan` ~~ search engine buat device yang terhubung ke internet, serem tapi asik
- `DNSDumpster` ~~ recon DNS records dan subdomain mapping
- `WHOIS` ~~ siapa yang punya domain ini?? ini jawabannya hihi

**Foto dan Geolocation**
- `ExifTool` ~~ baca metadata tersembunyi di foto, bisa tau GPS lokasi foto diambil
- `GeoGuessr` ~~ buat latihan geolocation dari foto/video (mainan tapi skill nyata)
- `Google Earth` ~~ satellite imagery buat verifikasi lokasi fisik

**Breach dan Credential**
- `HaveIBeenPwned` ~~ cek apakah email/passwordmu pernah kena breach
- `IntelX` ~~ search di paste sites, dark web leaks, dsb
- `Dehashed` ~~ database breach searching yang komprehensif

**People Search**
- `Pipl` ~~ agregasi profil orang dari berbagai sumber
- `Spokeo` ~~ US-focused people search engine
- `Intelius` ~~ public records aggregator

masih banyak lagi bestie~ buka langsung aja di app-nya buat eksplor semua kategori ehe :3
